# H2 到 MySQL 数据库迁移指南

本文档说明如何将项目从 H2 内存数据库迁移到 MySQL 持久化数据库。

## 迁移原因

- **数据持久化**：H2 是内存数据库，应用重启后数据丢失，不适合生产环境
- **性能优化**：MySQL 提供更好的并发性能和查询优化
- **生产就绪**：MySQL 是成熟的生产级数据库，支持主从复制、备份恢复等企业级特性
- **统一环境**：开发和生产使用相同的数据库，减少环境差异导致的问题

## 已完成的迁移工作

### 1. 依赖配置更新

**文件：`pom.xml`**

- 添加 MySQL 驱动依赖
- 将 H2 和 PostgreSQL 设置为可选依赖
- 保留 H2 依赖以便需要时快速切换

```xml
<!-- MySQL Database (推荐) -->
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <scope>runtime</scope>
</dependency>

<!-- H2 Database (开发用 - 可选) -->
<dependency>
    <groupId>com.h2database</groupId>
    <artifactId>h2</artifactId>
    <scope>runtime</scope>
    <optional>true</optional>
</dependency>
```

### 2. 数据源配置更新

**文件：`src/main/resources/application.yml`**

- 修改数据源为 MySQL
- 使用环境变量配置数据库连接
- 配置 HikariCP 连接池
- 更新 SQL 初始化配置

```yaml
spring:
  datasource:
    url: jdbc:mysql://${DB_HOST:localhost}:${DB_PORT:3306}/${DB_NAME:manqiyou}?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    driver-class-name: com.mysql.cj.jdbc.Driver
    username: ${DB_USERNAME:root}
    password: ${DB_PASSWORD:}
    hikari:
      minimum-idle: 5
      maximum-pool-size: 20
      idle-timeout: 600000
      max-lifetime: 1800000
      connection-timeout: 30000
  
  sql:
    init:
      mode: always
      schema-locations: classpath:schema-mysql.sql
      data-locations: classpath:data.sql
```

### 3. 数据库架构转换

**文件：`src/main/resources/schema-mysql.sql`**

创建了 MySQL 兼容的数据库架构，主要变更：

#### 自增主键
```sql
-- H2
id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY

-- MySQL
id BIGINT AUTO_INCREMENT PRIMARY KEY
```

#### 布尔类型
```sql
-- H2
is_active BOOLEAN DEFAULT TRUE

-- MySQL
is_active TINYINT(1) DEFAULT 1
```

#### 时间戳
```sql
-- H2
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP

-- MySQL
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
```

#### 表引擎和字符集
```sql
-- MySQL 特有配置
ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
```

#### 索引定义
```sql
-- H2（分离定义）
CREATE INDEX idx_routes_status ON routes(status);

-- MySQL（内联定义）
CREATE TABLE routes (
    ...
    INDEX idx_status (status)
) ENGINE=InnoDB;
```

## 回退到 H2（如需要）

如果需要临时回退到 H2 数据库：

### 1. 修改 `application.yml`

```yaml
spring:
  datasource:
    url: jdbc:h2:mem:manqiyou
    driver-class-name: org.h2.Driver
    username: sa
    password:
  
  sql:
    init:
      mode: always
      schema-locations: classpath:schema.sql  # 使用原始 H2 schema
      data-locations: classpath:data.sql
  
  h2:
    console:
      enabled: true
      path: /h2-console
```

```bash
mvnw.cmd spring-boot:run
```

## 常见问题

### Q: 迁移后数据会丢失吗？
A: H2 是内存数据库，本身就不保存数据。迁移到 MySQL 后，数据会持久化保存。

### Q: 可以同时使用 H2 和 MySQL 吗？
A: 不建议。应用同一时间只能连接一个数据库。但可以通过修改配置文件快速切换。

### Q: 迁移需要多长时间？
A: 整个迁移过程约 10-15 分钟，包括安装 MySQL、配置和验证。

### Q: 生产环境也要这样配置吗？
A: 生产环境建议使用云数据库服务（如阿里云 RDS），无需手动安装 MySQL。

### Q: 如何备份 MySQL 数据？
A: 使用 mysqldump 命令：
```bash
mysqldump -u manqiyou -p manqiyou > backup.sql
```

### Q: 如何恢复备份？
A: 使用 mysql 命令：
```bash
mysql -u manqiyou -p manqiyou < backup.sql
```

## 技术细节

### MyBatis-Plus 配置

MyBatis-Plus 自动适配不同数据库，无需修改代码：

```yaml
mybatis-plus:
  global-config:
    db-config:
      id-type: auto  # 自动识别数据库的自增策略
```

### 连接池配置

使用 HikariCP 连接池（Spring Boot 默认）：

```yaml
spring:
  datasource:
    hikari:
      minimum-idle: 5          # 最小空闲连接
      maximum-pool-size: 20    # 最大连接数
      idle-timeout: 600000     # 空闲超时（10分钟）
      max-lifetime: 1800000    # 连接最大生命周期（30分钟）
      connection-timeout: 30000 # 连接超时（30秒）
```

### 字符集配置

使用 UTF-8MB4 支持完整的 Unicode 字符（包括 emoji）：

```sql
CREATE DATABASE manqiyou 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;
```

## 后续优化建议

3. **读写分离**
   - 配置主从复制
   - 读操作分散到从库

4. **缓存策略**
   - 使用 Redis 缓存热点数据
   - 减少数据库查询压力

5. **监控告警**
   - 配置慢查询监控
   - 设置连接数告警
   - 监控磁盘空间
