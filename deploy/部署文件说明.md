# 部署文件说明

## 📁 新创建的部署文件清单

本次为阿里云部署创建了以下文件：

### 1. Docker 配置文件

#### `docker-compose.prod.yml` (项目根目录)
**用途**: 生产环境 Docker Compose 配置文件
**内容**:
- PostgreSQL 数据库容器配置
- Redis 缓存容器配置
- Spring Boot 后端容器配置
- Next.js 前端容器配置
- 网络和数据卷配置
- 健康检查配置

**使用方法**:
```bash
docker-compose -f docker-compose.prod.yml up -d --build
```

#### `backend/manqiyou-app/Dockerfile`
**用途**: 后端 Docker 镜像构建文件
**特点**:
- 多阶段构建（构建阶段 + 运行阶段）
- 使用 Maven 构建 JAR 包
- 基于 Eclipse Temurin JRE 17
- 非 root 用户运行
- 包含健康检查

#### `frontend/Dockerfile`
**用途**: 前端 Docker 镜像构建文件
**特点**:
- 多阶段构建（依赖 + 构建 + 运行）
- Next.js standalone 输出
- 基于 Node.js 20 Alpine
- 非 root 用户运行
- 包含健康检查

---

### 2. 环境配置文件

#### `.env.production` (项目根目录)
**用途**: 生产环境变量模板
**包含**:
- 数据库密码
- Redis 密码
- JWT 密钥
- API URL

**注意**: 部署时需要修改密码和密钥！

---

### 3. Nginx 配置文件

#### `deploy/nginx-manqiyou.conf`
**用途**: Nginx 反向代理配置
**功能**:
- HTTP 到 HTTPS 重定向
- SSL/TLS 配置
- 前端反向代理（端口 3000）
- 后端 API 反向代理（端口 8080）
- 静态资源缓存
- Gzip 压缩
- 安全响应头
- CORS 配置

**部署位置**: `/etc/nginx/sites-available/manqiyou`

---

### 4. 部署脚本

#### `deploy/quick-deploy.sh`
**用途**: 一键部署脚本
**功能**:
- 检查环境依赖
- 创建项目目录
- 克隆或更新代码
- 配置环境变量
- 构建并启动 Docker 容器
- 验证服务状态

**使用方法**:
```bash
bash deploy/quick-deploy.sh
```

#### `deploy/setup-ssl.sh`
**用途**: SSL 证书配置脚本
**功能**:
- 安装 Certbot
- 获取 Let's Encrypt 证书
- 配置自动续期
- 测试续期功能

**使用方法**:
```bash
sudo bash deploy/setup-ssl.sh
```

#### `deploy/deploy-to-aliyun.sh`
**用途**: 完整部署脚本（包含更多检查）
**功能**:
- 与 quick-deploy.sh 类似
- 增加了更多验证步骤
- 更详细的输出信息

## 📋 文件使用流程

### 第一步：准备阶段
1. 阅读 `PROJECT_SUMMARY.md` 了解项目
2. 阅读 `deploy/阿里云部署完整方案.md` 了解部署流程
3. 检查 `deploy/DEPLOYMENT_CHECKLIST.md` 确保准备就绪

### 第二步：配置阶段
1. 修改 `.env.production` 设置密码和密钥
2. 检查 `docker-compose.prod.yml` 配置
3. 检查 `deploy/nginx-manqiyou.conf` 配置

### 第三步：部署阶段
1. 运行 `deploy/quick-deploy.sh` 部署应用
2. 配置 Nginx（复制 nginx-manqiyou.conf）
3. 运行 `deploy/setup-ssl.sh` 配置 SSL

### 第四步：验证阶段
1. 使用 `deploy/DEPLOYMENT_CHECKLIST.md` 逐项检查
2. 测试所有功能
3. 记录部署信息

## 🚀 快速部署命令

如果所有文件都已准备好，可以使用以下命令快速部署：

```bash
# 1. 连接到服务器
ssh root@47.97.21.33

# 2. 克隆代码
sudo mkdir -p /var/www/manqiyou
sudo chown -R $USER:$USER /var/www/manqiyou
cd /var/www/manqiyou
git clone git@github.com:zhf186/mqyweb.git .

# 3. 配置环境变量
cp .env.production .env
nano .env  # 修改密码

# 4. 运行部署脚本
bash deploy/quick-deploy.sh

# 5. 配置 Nginx
sudo cp deploy/nginx-manqiyou.conf /etc/nginx/sites-available/manqiyou
sudo ln -s /etc/nginx/sites-available/manqiyou /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# 6. 配置 SSL
sudo nano deploy/setup-ssl.sh  # 修改邮箱
sudo bash deploy/setup-ssl.sh

# 7. 验证部署
curl https://www.zjmqy.cc
```

## 📞 获取帮助

如果在部署过程中遇到问题：

1. **查看日志**:
   ```bash
   docker-compose -f docker-compose.prod.yml logs -f
   sudo tail -f /var/log/nginx/manqiyou_error.log
   ```

2. **参考文档**:
   - `deploy/阿里云部署完整方案.md` - 完整部署指南
   - `deploy/DEPLOYMENT_CHECKLIST.md` - 检查清单
   - `deploy/README-ALIYUN.md` - 快速参考

3. **常见问题**:
   - 容器无法启动 → 检查端口占用和环境变量
   - Nginx 502 错误 → 检查后端容器状态
   - SSL 证书问题 → 检查域名解析和 80 端口
