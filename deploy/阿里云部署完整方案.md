# 漫骑游项目 - 阿里云部署完整执行方案

## 📋 项目概况

### 项目信息
- **项目名称**: 漫骑游官方网站 (Manqiyou)
- **Git 仓库**: git@github.com:zhf186/mqyweb.git
- **服务器 IP**: 47.97.21.33
- **域名**: www.zjmqy.cc
- **Web 服务器**: Nginx (已安装，有其他项目运行中)
- **容器化**: Docker (本机和服务器均已安装)

### 技术栈
- **前端**: Next.js 14 + TypeScript + Tailwind CSS
- **后端**: Spring Boot 3.2 + Java 17 + MyBatis-Plus
- **数据库**: PostgreSQL 16 (生产) / H2 (开发)
- **缓存**: Redis 7
- **进程管理**: PM2 (前端) + systemd (后端)

### 部署要求
1. ✅ 使用 Docker 容器化部署
2. ✅ 通过 Git 拉取代码
3. ✅ 配置 HTTPS 并自动续期
4. ✅ 不影响服务器现有项目
5. ✅ 使用 Nginx 反向代理

---

## 🎯 部署架构

```
Internet
    ↓
Nginx (80/443) - 反向代理
    ↓
    ├─→ www.zjmqy.cc → Next.js Frontend (Docker: 3000)
    └─→ www.zjmqy.cc/api → Spring Boot Backend (Docker: 8080)
            ↓
            ├─→ PostgreSQL (Docker: 5432)
            └─→ Redis (Docker: 6379)
```

## 📦 第三阶段：部署项目

### 3.1 克隆项目代码

```bash
# 创建项目目录
sudo mkdir -p /var/www/manqiyou
sudo chown -R $USER:$USER /var/www/manqiyou

# 克隆代码
cd /var/www/manqiyou
git clone git@github.com:zhf186/mqyweb.git .

# 确认代码已下载
ls -la
```

### 3.2 配置环境变量

```bash
cd /var/www/manqiyou

# 复制环境变量模板
cp .env.production .env

# 编辑环境变量（修改密码和密钥）
nano .env
```

**修改以下内容：**
```bash
# 数据库密码（请使用强密码）
DB_PASSWORD=your_strong_db_password_here

# Redis 密码（请使用强密码）
REDIS_PASSWORD=your_strong_redis_password_here

# JWT 密钥（使用随机字符串）
JWT_SECRET=$(openssl rand -base64 32)

# API URL（已配置好）
NEXT_PUBLIC_API_URL=https://www.zjmqy.cc/api
```

保存并退出（Ctrl+X, Y, Enter）

### 3.3 构建并启动 Docker 容器

```bash
cd /var/www/manqiyou

# 加载环境变量

docker-compose -f docker-compose.prod.yml up -d --build

# 查看构建进度
docker-compose -f docker-compose.prod.yml logs -f
```

- 后端构建：5-10 分钟
- 前端构建：3-5 分钟

## 🌐 第四阶段：配置 Nginx 反向代理

### 4.1 备份现有 Nginx 配置

```bash
# 备份现有配置
sudo cp -r /etc/nginx/sites-available /etc/nginx/sites-available.backup.$(date +%Y%m%d)
sudo cp -r /etc/nginx/sites-enabled /etc/nginx/sites-enabled.backup.$(date +%Y%m%d)
```

### 4.2 创建漫骑游 Nginx 配置

```bash
# 复制配置文件
sudo cp /var/www/manqiyou/deploy/nginx-manqiyou.conf /etc/nginx/sites-available/manqiyou

# 创建软链接启用站点
sudo ln -s /etc/nginx/sites-available/manqiyou /etc/nginx/sites-enabled/

# 测试 Nginx 配置
sudo nginx -t
```

**如果测试失败，检查：**
1. 配置文件语法是否正确
2. 端口是否被占用
3. SSL 证书路径（暂时注释掉 SSL 相关配置）

### 4.3 临时配置（HTTP only，用于获取 SSL 证书）

```bash
# 编辑配置文件，暂时注释掉 HTTPS 部分
sudo nano /etc/nginx/sites-available/manqiyou

# 注释掉 443 端口的 server 块
# 只保留 80 端口的配置，并修改为：

server {
    listen 80;
    listen [::]:80;
    server_name www.zjmqy.cc zjmqy.cc;

    # Let's Encrypt 验证路径
    location /.well-known/acme-challenge/ {
        root /var/www/certbot;
    }

    # 临时代理到前端（用于测试）
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # API 代理
    location /api/ {
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 4.4 重载 Nginx

```bash

sudo nginx -t

# 重载 Nginx
sudo systemctl reload nginx

# 检查状态
sudo systemctl status nginx
```

### 5.1 确保域名解析正确

```bash
nslookup www.zjmqy.cc
```

### 5.2 创建 Certbot 目录

```bash

```

### 5.3 获取 SSL 证书

```bash
cd /var/www/manqiyou/deploy

# 修改邮箱地址
sudo nano setup-ssl.sh
# 将 your-email@example.com 改为你的实际邮箱

# 添加执行权限
chmod +x setup-ssl.sh

# 运行 SSL 配置脚本
sudo ./setup-ssl.sh
```

**脚本会自动：**
1. 安装 Certbot
2. 获取 SSL 证书
3. 配置自动续期
4. 测试续期功能

### 5.4 更新 Nginx 配置启用 HTTPS

```bash
# 恢复完整的 Nginx 配置（包含 HTTPS）
sudo cp /var/www/manqiyou/deploy/nginx-manqiyou.conf /etc/nginx/sites-available/manqiyou

# 测试配置
sudo nginx -t

# 重载 Nginx
sudo systemctl reload nginx
```

### 5.5 验证 HTTPS

```bash
# 测试 HTTPS 访问
curl https://www.zjmqy.cc

# 检查证书信息
openssl s_client -connect www.zjmqy.cc:443 -servername www.zjmqy.cc < /dev/null

# 从浏览器访问
# https://www.zjmqy.cc
```

### 5.6 配置自动续期

```bash
# 查看 certbot timer 状态
sudo systemctl status certbot.timer

# 查看下次续期时间
sudo certbot certificates

# 手动测试续期（不会真正续期）
sudo certbot renew --dry-run
```

**自动续期说明：**
- Certbot 会每天检查两次证书
- 证书到期前 30 天自动续期
- 续期后自动重载 Nginx
- 无需人工干预

```bash

docker-compose -f docker-compose.prod.yml stop

# 停止并删除容器（保留数据）

docker-compose -f docker-compose.prod.yml down -v
```

### 8.4 数据库备份

```bash
# 创建备份目录
mkdir -p /var/www/manqiyou/backups

# 备份数据库
docker exec manqiyou-postgres pg_dump -U manqiyou_user manqiyou > /var/www/manqiyou/backups/backup_$(date +%Y%m%d_%H%M%S).sql

# 自动备份脚本
cat > /var/www/manqiyou/backup.sh << 'EOF'
#!/bin/bash
BACKUP_DIR="/var/www/manqiyou/backups"
DATE=$(date +%Y%m%d_%H%M%S)
docker exec manqiyou-postgres pg_dump -U manqiyou_user manqiyou > $BACKUP_DIR/backup_$DATE.sql
# 删除 7 天前的备份
find $BACKUP_DIR -name "backup_*.sql" -mtime +7 -delete
EOF

chmod +x /var/www/manqiyou/backup.sh

# 添加到 crontab（每天凌晨 2 点备份）
(crontab -l 2>/dev/null; echo "0 2 * * * /var/www/manqiyou/backup.sh") | crontab -
```

### 8.5 恢复数据库

```bash
# 恢复数据库
docker exec -i manqiyou-postgres psql -U manqiyou_user manqiyou < /var/www/manqiyou/backups/backup_YYYYMMDD_HHMMSS.sql
```

### 9.2 配置 Fail2ban

```bash
# 安装 Fail2ban
sudo apt install -y fail2ban

# 创建本地配置
sudo cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local

# 编辑配置
sudo nano /etc/fail2ban/jail.local

# 启用 Nginx 保护
[nginx-http-auth]
enabled = true

[nginx-noscript]
enabled = true

[nginx-badbots]
enabled = true

# 启动服务
sudo systemctl enable fail2ban
sudo systemctl start fail2ban

# 查看状态
sudo fail2ban-client status
```
