# CMS页面编辑器增强 - 需求文档

## 项目概述

扩展现有的CMS内容管理系统，使其能够管理网站所有主要页面的文字内容和图片资源，实现真正的"所见即所得"的页面编辑体验。

## 目标页面

需要支持完整CMS管理的7个主要页面：

1. **首页** (/) - 已部分完成，需要补充图片管理
2. **E-BIKE** (/ebike) - 需要完整实现
3. **骑游线路** (/routes) - 需要完整实现
4. **在地好物** (/goods) - 需要完整实现
5. **社群活动** (/community) - 需要完整实现
6. **合作伙伴** (/partners) - 需要完整实现
7. **关于我们** (/about) - 需要完整实现

## 核心需求

### 需求1：页面内容结构化管理

**用户故事**: 作为内容管理员，我希望能够在CMS后台看到每个页面的完整内容结构，包括所有文字字段和图片字段，以便我能够系统地管理页面内容。

**验收标准**:
1. 每个页面在数据库中有对应的page记录
2. 每个页面的所有文字内容都有对应的content_item记录
3. 每个页面的所有图片都有对应的content_item记录（类型为image）
4. 内容项按照页面结构分组和排序
5. 支持中英文双语内容管理

### 需求2：文字内容编辑

**用户故事**: 作为内容管理员，我希望能够编辑页面上的所有文字内容，包括标题、描述、段落等，并且修改后能立即在前端页面看到效果。

**验收标准**:
1. 支持三种文字类型：
   - text: 单行文本（标题、标签等）
   - textarea: 多行文本（简短描述）
   - richtext: 富文本（长篇内容，支持格式化）
2. 每个文字字段都有中文和英文版本
3. 支持设置最大长度限制
4. 支持标记必填字段
5. 保存后前端实时生效（通过API获取）

### 需求3：图片内容管理

**用户故事**: 作为内容管理员，我希望能够管理页面上的所有图片，包括上传新图片、替换现有图片、设置图片的alt文本等。

**验收标准**:
1. 支持image类型的content_item
2. 图片字段存储asset_id（关联到cms_assets表）
3. 在编辑器中可以：
   - 预览当前图片
   - 从资源库选择图片
   - 上传新图片
   - 设置图片的中英文alt文本
4. 支持不同尺寸的图片（hero图、缩略图等）
5. 图片更换后前端实时生效

### 需求4：页面预览功能

**用户故事**: 作为内容管理员，我希望在保存修改前能够预览页面效果，确保内容显示正确。

**验收标准**:
1. 在内容编辑页面提供"预览"按钮
2. 预览显示当前编辑的内容（未保存的修改）
3. 预览支持中英文切换
4. 预览界面接近实际前端页面效果

### 需求5：批量内容初始化

**用户故事**: 作为系统管理员，我希望能够快速为所有页面初始化CMS内容项，将现有的硬编码内容迁移到CMS系统中。

**验收标准**:
1. 提供SQL脚本为每个页面创建page记录
2. 提供SQL脚本为每个页面创建所有content_item记录
3. 脚本包含当前页面的所有文字和图片内容
4. 脚本可重复执行（先删除后插入）
5. 包含合理的display_order排序

### 需求6：前端页面CMS集成

**用户故事**: 作为开发者，我希望前端页面能够从CMS API获取内容并渲染，替代原有的硬编码内容。

**验收标准**:
1. 每个页面组件使用getPageContent()获取CMS内容
2. 使用getContent()函数渲染文字内容
3. 使用getImageUrl()函数渲染图片
4. 保留fallback机制（CMS加载失败时使用默认值）
5. 支持loading状态显示

## 技术要求

### 数据库设计

#### cms_pages表
```sql
- id: 页面ID
- slug: 页面标识（如'home', 'ebike', 'routes'等）
- name_zh: 中文页面名称
- name_en: 英文页面名称
- description: 页面描述
- is_active: 是否启用
```

#### cms_content_items表
```sql
- id: 内容项ID
- page_id: 所属页面ID
- field_key: 字段键名（如'hero.title', 'hero.image'）
- field_type: 字段类型（text/textarea/richtext/image）
- content_zh: 中文内容（文字）或asset_id（图片）
- content_en: 英文内容（文字）或asset_id（图片）
- max_length: 最大长度（文字字段）
- is_required: 是否必填
- display_order: 显示顺序
- version: 版本号（乐观锁）
```

### API设计

#### 公共API（前端使用）
- `GET /api/public/content/pages/{slug}` - 获取页面内容
- `GET /api/public/assets/{assetId}` - 获取图片信息

#### 管理API（后台使用）
- `GET /api/admin/content/pages` - 获取所有页面列表
- `GET /api/admin/content/pages/{pageId}` - 获取页面详情和内容项
- `PUT /api/admin/content/items/{itemId}` - 更新内容项
- `POST /api/admin/content/items/{itemId}/image` - 更新图片内容项

### 前端组件

#### ContentEditor组件增强
- 支持image类型字段编辑
- 集成AssetPicker组件选择图片
- 显示图片预览
- 支持上传新图片

#### ImagePicker组件（新增）

- 打开资源库选择图片
- 支持上传新图片
- 设置图片alt文本

## 风险和限制

### 风险
1. 大量页面内容迁移可能出错
2. 图片引用关系复杂
3. 前端性能影响（多次API调用）

### 限制
1. 不支持页面结构调整（只能编辑内容）
2. 不支持动态添加/删除内容块
3. 图片尺寸需要预先定义
